01快速上手

第一次使用只需要四步：启动、装插件、搜索、播放。

  1. 双击 MusicFree.exe 启动

    这是便携版，所有配置和歌单数据都保存在程序目录的 portable/userData 下，不写系统用户目录，整个文件夹拷走即可迁移。

  2. 安装至少一个插件

    左侧栏点「插件管理」→「从网络安装」，粘贴以 .js 或 .json 结尾的插件地址；也可以在「订阅设置」里填插件订阅链接批量更新。插件负责取歌、取歌词、取 MV，不装插件搜索不到任何内容。推荐直接使用第 2 节的清雅音乐插件源。

  3. 在顶部搜索框搜索

    输入歌名、歌手或关键词后回车。点输入框会显示历史搜索，最多保留 30 条（条数可在设置里改）。

  4. 双击歌曲播放

    双击列表中的歌曲即可播放。默认行为是「用当前列表替换播放队列」，可在 设置 → 播放 中改为追加到队列。

提示

插件提供音乐数据，主题包负责界面外观，两者互不替代。歌曲能不能播、歌词有没有，取决于插件覆盖的平台与音源质量。

02推荐插件源：清雅音乐

本机使用的插件仓库，也是插件更新的唯一来源。

ElegantMusic（清雅音乐）是 MusicFree 桌面版的插件开发仓库，收录了针对桌面版增强的一整套插件。除了基础搜索与播放，还补上了逐字歌词、卡拉 OK 伴奏候选、完整版替换和 MV 搜索。仓库地址：github.com/acientemple/ElegantMusic

包含的插件

安装方法

  1. 打开「插件管理 → 从网络安装」

    插件地址需要以 .js 或 .json 结尾。

  2. 粘贴插件链接

    格式为 https://raw.githubusercontent.com/acientemple/ElegantMusic/master/plugins/<插件文件名>，例如 .../plugins/qq-music.js。按需逐个安装。

  3. 确认插件出现在列表中

    安装成功后即可使用；若界面暂时没有生效，重启一次应用。

提示

到 设置 → 插件 打开「打开软件时自动更新插件」，以后每次启动都会检查这些插件的更新。

说明

这套插件和本说明书描述的功能互相配合：逐字歌词用于卡拉 OK 扫光，伴奏候选用于切换原唱与伴奏，完整版搜索用于替换只能试听的音源，MV 候选带有官方与伴奏标记。

界面结构示意：从上到下依次为工具栏、侧边栏 + 内容区、播放条。

顶部工具栏

  • 后退 / 前进：在页面之间导航。
  • 搜索框：全局搜索，点击显示搜索历史。
  • 设置：打开设置页（十组设置项，见第 14 节）。
  • 主题：打开主题页，切换本地主题或逛主题市场。
  • 最小化 与 迷你模式：迷你模式会收起为主窗口的小型形态。
  • 退出：按设置里的「单击退出按钮时」行为执行（退出应用或最小化到托盘）。

左侧边栏

  • 排行榜：来自插件的榜单列表。
  • 热门歌单：插件提供的推荐歌单。
  • 下载管理：下载队列与历史。
  • 本地音乐：扫描到的本地文件，支持列表、作者、专辑、文件夹四种视图。
  • 插件管理：安装、更新、卸载插件，管理订阅与用户变量。
  • 最近播放：自动记录的播放历史，可从这里定位歌曲。
  • 我的歌单：本地歌单列表，标题右侧有三个按钮：导入歌单、导出全部歌单、新建歌单。
  • 我的收藏：收藏的外部歌单（收藏按钮在歌单页右上角）。

底部播放条

  • 进度条：拖动调整播放位置。
  • 左侧歌曲信息：封面、歌名、歌手，点歌名区域打开歌曲详情页（歌词页）。
  • 中间控制区：上一首、播放 / 暂停、下一首；点按钮之外的空白处会定位当前歌曲（第 7 节）。
  • 右侧按钮：音质、倍速、音量、桌面歌词、卡拉 OK、可视化、循环模式、播放列表。

04搜索与播放

搜索

顶部搜索框内输入关键词回车。搜索会同时询问所有已安装的插件，结果页按「单曲 / 歌单」分类展示。搜索历史保存在本地，可在输入框下拉中查看或清除。

开始播放

  • 双击歌曲行播放；双击行为可在 设置 → 播放 改为「追加到播放队列」。
  • 歌单页顶部有「播放」「添加」「收藏」按钮，可一键把整个歌单加入队列。
  • 播放失败时按 设置 → 播放 → 「播放失败时」的策略处理：暂停或自动播放下一首。
  • 播放中途音源中断时，播放器会尝试自动换源继续播放，并提示「音源中断，已自动换源继续播放」。

歌曲右键菜单

在任意歌曲列表上右键，可执行：下一首播放、搜索歌曲、搜索 MV、编辑歌曲信息、添加到歌单、从歌单内删除、删除本地下载、打开歌曲所在文件夹、校正时长。

说明

「搜索歌曲」会在所有支持该能力的插件里查找同一首歌的其他版本，用来替换只能试听的半截音源；「校正时长」在时长显示错误时使用，播放一次也会自动校正。

05我的歌单

本地歌单与你的播放数据都保存在应用数据库里，随应用目录迁移。

新建与管理

  • 新建歌单：点「我的歌单」标题旁的 + 按钮，输入名称。
  • 重命名 / 删除：在歌单上右键，选「重命名歌单」或「删除歌单」。默认的「我喜欢」歌单不能重命名或删除。
  • 导出歌单：右键单个歌单选「导出歌单」，或点标题旁的导出按钮导出全部，生成 JSON 备份文件。
  • 导入歌单：点标题旁的导入按钮，选择插件并粘贴歌单链接；也支持导入 MusicFree 导出的 JSON 备份。

把歌加进歌单

  • 列表里右键歌曲 →「添加到歌单」，选择目标歌单。
  • 点击歌曲行首的心形按钮，收藏到「我喜欢」。
  • 在歌单内可直接拖动歌曲调整顺序。

收藏外部歌单

打开任意在线歌单，点歌单页操作区的「收藏」按钮即可加入「我的收藏」；再次点击可取消收藏。

新功能

在侧边栏双击任意歌单，可让歌单页在「第一页」和「最后一页」之间切换，长歌单里快速回到顶部或跳到底部。详见第 8 节。

06播放控制

基本控制

  • 播放 / 暂停、上一首、下一首位于播放条中间。
  • 进度条可拖动；右侧循环按钮在三种模式间切换：列表循环 → 单曲循环 → 随机播放。
  • 音量按钮点开可拖动滑块，点击喇叭图标静音 / 恢复。

音质与倍速

  • 音质：点右侧音质按钮切换标准 / 高 / 超高等等级；菜单里可选择「仅设置当前歌曲」，否则作为默认音质。
  • 倍速：点右侧倍速按钮选择播放速度。

播放队列

点播放条最右侧的播放列表按钮打开队列面板。面板会盖在界面最上层，点面板外区域关闭。队列中可拖动排序、右键移除、点击定位到歌曲所在歌单。

说明

播放队列和「我的歌单」是两个概念：队列是当前播放顺序的临时列表，歌单是持久保存的收藏。双击歌曲默认会替换队列。

07定位当前歌曲

播放一首歌时，想知道它在哪个歌单里、快速跳过去，用这个功能。

怎么用

  1. 点播放条中间的空白处

    三个控制按钮之外、播放条中间区域的空白处都可以点。鼠标悬停时会出现「定位到当前歌曲所在的歌单」提示。

  2. 自动跳转到歌单

    应用会在本地歌单里查找包含这首歌的歌单；同时出现在多个歌单时，跳到最近加入的那个。跳转后列表自动滚到该歌曲并选中。

  3. 侧边栏同步展开

    「我的歌单」折叠区会自动展开，并把目标歌单滚动到侧边栏可见范围，高亮当前歌单。

细节

  • 如果歌曲不在任何歌单里，但出现在「最近播放」中，会跳到最近播放页。
  • 两者都找不到时，提示「这首歌还不在任何歌单里，先收藏到歌单里就能定位了」。
  • 定位时会自动关闭盖在上面的歌词详情页和 MV 窗口，保证你能看到歌单页。
  • 没有正在播放的歌曲时，点空白处没有反应。
  • 播放列表面板里的歌曲也支持定位，行为一致。

08双击歌单跳首尾

长歌单里来回滚很费劲时，双击侧边栏的歌单名即可在首尾之间切换。

第一次双击

回到第一页

歌单内容区平滑滚动到顶部，也就是列表的第一页。

再次双击

跳到最后一页

滚动到列表最底部，查看最后一批歌曲。

循环

交替切换

之后每次双击都在顶部和底部之间来回切换。

说明

双击的不是当前歌单时，会先切换到这个歌单（新页面本来就在顶部），下一次双击再滚到底部。单击行为不变，仍然是切换歌单。

09歌词与歌曲详情

打开详情页

点播放条左侧的歌名区域或封面旁的展开按钮，打开全屏歌曲详情页。页面上有歌词、封面和歌曲操作按钮；按 Esc 或点关闭按钮退出。

歌词

  • 搜索歌词：手动选择插件搜索并关联歌词。
  • 智能匹配歌词：按歌名与歌手在各插件中搜索候选，按匹配度排序。设置里可调整「自动应用的匹配度」阈值（默认 0.8）。
  • 声音识别歌词：录制当前播放音频，用 audd.io 识别真实歌名后再搜歌词。需要在设置里填入 audd.io 的免费 Token。
  • 翻译：有翻译歌词时显示「显示翻译 / 隐藏翻译」。
  • 关联 / 取消关联歌词：歌词区域右键操作。
  • 下载歌词：右键歌词可导出 .lrc 或 .txt 文件。

歌曲操作按钮

  • 搜索歌曲：在其他插件中查找同一首歌的可完整播放版本，可直接替换当前音源。
  • 搜索 MV：搜索这首歌的 MV 候选；观看 MV：已有绑定 MV 时直接播放。
  • 歌曲信息：编辑歌名、歌手、专辑，可恢复默认。本地音乐不支持编辑。

桌面歌词

点播放条右侧的歌词按钮打开桌面歌词窗口。可在设置里调整字体、字号、颜色、描边色；窗口可锁定位置，锁定后不能拖动。全局快捷键也可绑定桌面歌词开关（第 13 节）。

10卡拉 OK、MV 与可视化

卡拉 OK

播放条右侧的麦克风按钮打开卡拉 OK 窗口。对着麦克风跟唱，结束后给出节奏、完整度、音高三项评分。窗口内可以切换原唱 / 伴奏、显示或隐藏翻译；伴奏版本来自支持该能力的插件。

MV 播放器

从歌曲详情页点「观看 MV」或「搜索 MV」选中候选后，MV 会以独立窗口播放，支持最大化、最小化、下载视频。窗口位置可拖动。

可视化

播放条右侧的频谱按钮打开可视化窗口，内置八种效果：条形频谱、示波器、频谱山脊、粒子、几何、流体、电池、烟花。默认随机轮换，也可在 设置 → 可视化 中固定效果。

注意

部分在线音源跨域限制音频数据读取，可视化会提示「此音源无法可视化」。这是浏览器安全策略，不是故障。

11本地音乐与下载

本地音乐

  • 首次进入时点「添加文件夹」，选择要扫描的目录；文件增删会实时同步。
  • 提供列表、作者、专辑、文件夹四种视图，支持站内搜索。
  • 右键本地歌曲可「打开歌曲所在文件夹」、「删除本地下载」。

下载管理

  • 歌曲右键或详情页可下载到本地，下载目录默认是系统「下载」文件夹，可在 设置 → 下载 中修改。
  • 可设置默认下载音质、音质缺失时的策略、最多同时下载数（默认 5 个）。
  • 下载失败或超时会重试；下载不完整的文件会被自动丢弃，避免出现能播放但截断的音频。

12主题

界面外观由主题包决定，和插件是两套独立的东西。

  • 点顶部「主题」按钮进入主题页，分「本地主题」和「主题市场」两个标签。
  • 本地主题：已安装的主题，点「使用主题」立即切换；可卸载。
  • 主题市场：浏览在线主题，点「下载并使用」安装。
  • 手动安装：把主题文件夹放到程序目录的 portable/userData/musicfree-themepacks/，重启应用后在本地主题中出现。
说明

本机内置 Windows Media Player 风格、iTunes 风格等深色 / 浅色主题，部分主题带频谱柱可视化。切换主题不会影响歌单、插件和设置数据。

13快捷键

快捷键分为「软件内快捷键」和「全局快捷键」两类，都可自由绑定。

功能默认软件内快捷键说明
播放上一首↑可在设置中改键
播放下一首↓可在设置中改键
快退 5 秒←可在设置中改键
快进 5 秒→可在设置中改键

可绑定的功能

  • 播放 / 暂停
  • 播放上一首 / 下一首
  • 快退 5 秒 / 快进 5 秒
  • 增加音量 / 降低音量
  • 打开 / 关闭桌面歌词
  • 喜欢 / 不喜欢当前歌曲
  • 显示 / 隐藏主窗口（仅全局快捷键可用）

两类快捷键的区别

  • 软件内快捷键：默认启用，只在主窗口聚焦时生效。
  • 全局快捷键：默认关闭，开启后在任意应用下都能响应，适合切歌、显示主窗口。
提示

如果某个键与其他软件冲突，到 设置 → 快捷键 里点击重新绑定。绑定为空表示不使用该键。

14设置项

设置页分十组，下面按组说明常用项。

常规

  • 启动时检查更新、检查预发布版本。
  • 单击退出按钮时：退出应用或最小化到托盘。
  • 任务栏缩略图样式（当前播放歌曲封面或主窗口界面）。
  • 搜索历史最多保存条数、歌曲列表隐藏列。
  • 界面语言（简体中文 / 繁体中文 / English）、主窗口始终置顶。

播放

  • 默认播放音质、音质缺失时的策略（更低 / 更高 / 不找替代）。
  • 播放失败时：暂停或自动下一首。
  • 双击音乐列表时：替换播放队列或追加到队列。
  • 歌单内搜索是否区分大小写。
  • 音频输出设备选择、设备移除时继续播放或暂停。

下载

  • 下载目录、默认下载音质、音质缺失策略、最多同时下载数。

歌词

  • 桌面歌词开关与锁定、字体、字号、字体颜色、描边颜色。
  • 歌词缺失时智能匹配，及自动应用的匹配度阈值。
  • 声音识别 Token（audd.io）。

插件

  • 打开软件时自动更新插件。
  • 安装插件时不校验版本（仅在明确知道后果时开启）。

快捷键 / 网络 / 可视化 / 关于

  • 快捷键：见第 13 节。
  • 网络：启用网络代理（主机、端口、账号、密码）；查看并清空本地缓存。
  • 可视化：启用可视化窗口、固定效果或随机轮换。
  • 关于：当前版本、检查更新、开源协议与官网入口。

15备份与恢复

文件备份

设置 → 备份与恢复 → 文件备份，可把歌单备份到本地或从备份文件恢复。恢复时可选「追加到已有歌单末尾」或「覆盖已有歌单」。

WebDAV 备份

填写 WebDAV 服务的 URL、账号、密码后即可远程备份与恢复歌单，适合在多台设备间同步。

注意

备份包含的是歌单数据，不包含插件文件、主题包和设置。换机器时请同时拷贝整个 portable/userData 目录。

16常见问题

搜不到任何歌曲

先确认已安装插件且插件处于可用状态。插件可能临时限流或接口失效，可到插件管理里检查更新，或更换插件。

歌曲播放失败

多数是音源失效或该音质不可用。到 设置 → 播放 调整音质缺失策略；也可以右键歌曲用「搜索歌曲」换一个可播放的版本。

下载的文件不完整

播放器会检测文件完整性并丢弃截断的文件，提示后重试即可。

桌面歌词不显示

确认已开启桌面歌词（播放条右侧按钮或设置项），并检查是否被其他窗口遮挡。锁定状态下窗口不可拖动。

可视化提示「此音源无法可视化」

在线音源存在跨域限制，浏览器不允许读取音频数据。换用本地音乐或其他音源即可。

更新后插件或数据异常

大版本更新可能重置插件排序与插件内填写的用户变量（如 Cookie），旧数据库会备份到应用目录的 backups 文件夹。更新前请确认提示内容。

点击定位没反应

确认当前有正在播放的歌曲；另外歌曲需要先加入某个歌单或出现在最近播放中才能定位。

17数据与文件位置

便携版的所有用户数据都在程序目录内，整个文件夹可以整体备份或迁移。

路径内容
portable/userData/config.json应用设置（扁平键名，如 normal.alwaysOnTop）
portable/userData/musicfree-plugins/已安装的插件文件
portable/userData/musicfree-themepacks/已安装的主题包
portable/userData/IndexedDB/歌单、收藏等数据库
portable/userData/Cache/缓存，可在设置 → 网络 中清空
portable/userData/backups/更新前的自动备份
重要

覆盖安装新版本时不要删除或覆盖 portable/userData 目录，否则插件、歌单与设置都会丢失。
